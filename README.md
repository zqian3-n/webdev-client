# Web Development A1

Lab 1 HTML examples and a first Kambaz prototype, built with Next.js App Router.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. The root route goes to Sign in. The Labs link shows Lab 1. Sign in opens the Dashboard, where course cards lead to Home, Modules, and Assignments. This is a Chapter 1 interface prototype, so form submissions and course buttons do not store data yet.
